**MyEvent**

**Descriere:**
O soluție digitală pentru organizarea și monitorizarea evenimentelor, care permite stocarea structurată și căutarea rapidă a datelor.
uncționalități Principale (Cerințe):

**Functionalitate**

Identificare: Introducerea numelui unic pentru fiecare eveniment.

Planificare: Gestionarea datei și a locului de desfășurare.

Organizare: Definirea organizatorului și a numărului de participanți.

Clasificare: Selectarea tipului de eveniment dintr-o listă predefinită (Cultural, Sportiv, Științific, Divertisment).

Feedback: Posibilitatea de a introduce rating-uri multiple pentru calcularea automată a unei medii de satisfacție.
